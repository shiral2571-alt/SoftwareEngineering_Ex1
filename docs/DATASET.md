# Data Set

## Real data

| File | Source | Shape | Voxel type | Notes |
|---|---|---|---|---|
| `data/MRHead_1.nrrd` | 3D Slicer sample data (MRHead), the file linked in the assignment | 256 × 256 × 130 | int16 | Gzip-encoded. Space `left-posterior-superior`, spacing 1 × 1 × 1.3 mm. |

Axis meaning of MRHead in voxel indices (from `space directions`):

| Array axis | Direction | Plane with this axis fixed |
|---|---|---|
| 0 | anterior → posterior | coronal |
| 1 | superior → inferior | axial |
| 2 | left → right | sagittal |

Because planes are given in voxel indices (SRS assumption A1), "constant `z`" in this file is
a **sagittal** slice, and the 1.3 mm spacing of axis 2 is not compensated.

More volumes for the same tool are available from the *Sample Data* module of 3D Slicer
(for example MRBrainTumor1, CTChest, CTACardio). Any 3D scalar NRRD with axes smaller than
1024 works.

## Plane files

| File | Planes | Description |
|---|---|---|
| `data/planes_sagittal5.csv` | 5 trapezoids | The first hand-written test: 5 sagittal rectangles |
| `data/planes_sweep.csv` | 130 trapezoids | Sagittal sweep through every left-right index |
| `data/planes_rotate.csv` | 90 trapezoids | Vertical rectangle through the head center, rotating 0°→180° |
| `data/planes_triangle.csv` | 60 triangles | Isosceles triangle hanging from the top of the head, rotating 0°→180° |
| `data/planes_tumble.csv` | 120 trapezoids | Square through the head center turning freely in 3D (no fixed rotation axis), always oblique |

The last four are generated by `python experiments/make_planes.py`.

`python experiments/make_random_planes.py [N] [--seed S] [--min-inside F]` writes
`data/planes_random.csv`: N (default 60) random rectangles and triangles near the head center,
each with a random 3D orientation. Planes with less than F (default 0.8) of their area inside
the volume are drawn again, so most of every frame shows the head. Without `--seed` the planes
are new on every run, so the file is not committed.
